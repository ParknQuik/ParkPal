# Grill Me

Use this skill when the user explicitly asks to be grilled on an idea, plan, or design. It is suited to planning conversations, including Plan mode, where the goal is to expose assumptions and resolve important choices before settling on an approach.

## Interview

- Start from the user's stated goal and any context already provided. Do not ask them to repeat known details.
- Ask one focused question at a time. Prefer questions whose answers could change the plan: desired outcome, users, constraints, priorities, risks, dependencies, or success criteria.
- Be direct and constructive. Point out contradictions, hidden assumptions, and tradeoffs when relevant, then ask what the user wants to do about them.
- Adapt follow-up questions to each answer. Stop when the remaining uncertainty would not materially change the plan, or when the user asks to stop.
- Do not invent a required question count or keep interviewing for completeness alone.

## Finish

When the user is ready, summarize the clarified goal and decisions, then provide a concise, actionable plan in the active planning format. In Plan mode, return the plan for review and do not implement it. If the user asks to stop before the plan is settled, summarize what is known and identify the open decisions without forcing a conclusion.
